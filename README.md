# Black Myth: Wukong Benchmark Automation Tool

## Описание
Консольное приложение на C#, которое автоматизирует процесс тестирования производительности в **Black Myth: Wukong Benchmark Tool**. Инструмент выполняет два последовательных прохода бенчмарка:
1. **CPU-тест** — с настройками, минимизирующими нагрузку на видеокарту.
2. **GPU-тест** — с настройками, обеспечивающими максимальную нагрузку на видеокарту.

После завершения каждого прохода программа считывает результаты, парсит их и выводит в консоль сводный отчёт с характеристиками системы и показателями FPS.

## Инструкция по запуску

### Требования
*   ОС: Windows 10/11
*   .NET SDK (версия 6.0 или 8.0)
*   Установленный **Black Myth: Wukong Benchmark Tool** (через Steam)
*   NuGet-пакет `System.Management`

### Настройка перед запуском
Перед первым запуском откройте файл `Program.cs` и укажите актуальные пути к файлам в переменных:
*   `benchmarkExePath` — путь к исполняемому файлу бенчмарка (`.exe`).
*   `configPath` — путь к файлу конфигурации графики (обычно `GameUserSettings.ini`).
*   `resultPath` — путь к файлу, в который бенчмарк сохраняет результаты.
